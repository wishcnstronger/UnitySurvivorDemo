# Vampire Survivors Like Demo

一个基于 Unity 开发的 2D 生存类 Roguelike 游戏 Demo。

本项目用于学习 Unity 游戏开发流程，并探索 AI 辅助游戏开发模式。


## 项目介绍

本项目参考《Vampire Survivors》等生存类游戏设计。

玩家需要在不断生成的敌人中生存，通过击败敌人获得经验并选择强化能力，逐渐构建自己的战斗流派。


## 核心玩法


玩家移动

↓

敌人生成

↓

自动攻击

↓

击败敌人

↓

获得经验

↓

升级选择能力

↓

强化角色

↓

挑战更强敌人



## 项目特色

### 1. Roguelike成长系统

玩家每次升级时可以选择不同强化：

- 攻击提升
- 攻速提升
- 移速提升

通过不同选择形成不同Build。


### 2. 自动战斗机制

玩家主要进行移动决策。

攻击系统自动运行。

强调：

- 走位
- Build选择
- 生存策略


### 3. AI辅助开发

项目开发过程中使用 AI Agent 辅助：

- 代码生成
- Debug
- 架构讨论
- 开发流程管理

同时通过人工理解和调整保证代码质量。
